# duetPrintGuard - 3.7.x branch

Real-time print failure detection for Duet3D printers. This branch is the code for duetPrintGuard 2.x, for DWC / DSF 3.7.

The documentation - installation, configuration, operation and change notes - is on the main branch, in a folder for each version:

- [duetPrintGuard 2.2](https://github.com/stuartofmt/duetPrintGuard/tree/main/docs/2.2)
- [duetPrintGuard 2.1](https://github.com/stuartofmt/duetPrintGuard/tree/main/docs/2.1)
- [All versions](https://github.com/stuartofmt/duetPrintGuard#versions)

The plugin zip files are on the [releases](https://github.com/stuartofmt/duetPrintGuard/releases) page.

Building the pages: see [ui/README.md](ui/README.md).
